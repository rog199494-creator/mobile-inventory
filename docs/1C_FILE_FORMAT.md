# Формат файлов для интеграции с 1С / SAP

> Документ предназначен для 1С-программиста или администратора системы, настраивающего выгрузку/загрузку файлов.

---

## Принцип работы

Обмен данными между **1С / SAP** и приложением **Мобильная инвентаризация** происходит **через файлы** — без сетевой интеграции, паролей и HTTP-сервисов.

```
[1С] ──экспорт остатков──▶ файл CSV/XLSX ──▶ [Загрузить в приложение]
[Приложение] ──результаты ревизии──▶ файл CSV/XLSX ──▶ [Загрузить в 1С]
```

**Правило: 1 файл = 1 склад = 1 сессия ревизии.**

---

## 1. Формат файла импорта (из 1С → в приложение)

### 1.1 Колонки

| Колонка | Тип | Обязательная | Описание |
|---------|-----|:---:|---------|
| `Артикул` | Строка | ✅ | Артикул товара в 1С |
| `Штрихкод` | Строка | ⬜ | Штрихкод (EAN-13 или другой) |
| `Наименование` | Строка | ✅ | Полное наименование товара |
| `ЕдиницаИзмерения` | Строка | ⬜ | Единица измерения (шт, кг, л и т.д.) |
| `Остаток` | Число | ✅ | Остаток по данным 1С на момент выгрузки |
| `Цена` | Число | ⬜ | Цена единицы (используется при расчёте суммы расхождений) |
| `Склад` | Строка | ⬜ | Название склада (заполняется автоматически в превью импорта) |

> **Допустимые синонимы колонок** (приложение принимает как русские, так и английские названия):
> - `Артикул` → `SKU`, `sku`, `Код`, `Code`
> - `Штрихкод` → `Barcode`, `barcode`, `EAN`
> - `Наименование` → `Name`, `name`, `Product Name`, `Название`
> - `ЕдиницаИзмерения` → `Unit`, `unit`, `ЕИ`
> - `Остаток` → `Expected Qty`, `qty`, `Quantity`, `stock`
> - `Цена` → `Price`, `price`
> - `Склад` → `Warehouse`, `warehouse`

### 1.2 Пример CSV (разделитель — `;`)

```csv
Артикул;Штрихкод;Наименование;ЕдиницаИзмерения;Остаток;Цена;Склад
COFFEE-500;8901234567890;Кофе зерновой Premium 500г;шт;150;12.99;ЦС-01
TEA-100;8901234567891;Чай зелёный органик 100г;шт;200;8.50;ЦС-01
CHOC-100;8901234567892;Шоколад тёмный 100г;шт;300;4.25;ЦС-01
```

### 1.3 Пример XLSX

Файл Excel должен содержать один лист с данными. Первая строка — заголовки колонок (см. таблицу выше).

| Артикул | Штрихкод | Наименование | ЕдиницаИзмерения | Остаток | Цена | Склад |
|---------|----------|-------------|-----------------|---------|------|-------|
| COFFEE-500 | 8901234567890 | Кофе зерновой Premium 500г | шт | 150 | 12.99 | ЦС-01 |
| TEA-100 | 8901234567891 | Чай зелёный органик 100г | шт | 200 | 8.50 | ЦС-01 |

### 1.4 Технические требования

- **Форматы файлов:** `.csv`, `.xlsx`, `.xls`
- **Кодировка CSV:** UTF-8 (с BOM или без — приложение определяет автоматически)
- **Разделитель CSV:** `;` (точка с запятой) или `,` (запятая) — определяется автоматически
- **Десятичный разделитель чисел:** `.` (точка) или `,` (запятая) — оба варианта поддерживаются
- **Строки с ошибками** (пустой артикул/наименование, нечисловой остаток) не прерывают импорт — они отображаются в превью

## 2. Формат файла экспорта (из приложения → в 1С)

После завершения ревизии приложение формирует файл с результатами.

### 2.1 Колонки экспорта

| Колонка | Описание |
|---------|---------|
| `Артикул` | Артикул товара |
| `Штрихкод` | Штрихкод товара |
| `Наименование` | Наименование товара |
| `ЕдиницаИзмерения` | Единица измерения |
| `ОстатокПоДанным1С` | Остаток по данным 1С (план) |
| `ФактическоеКоличество` | Фактическое количество по результатам ревизии |
| `Расхождение` | Разница: Факт − Остаток 1С (отрицательное = недостача, положительное = излишек) |
| `Комментарий` | Комментарий (опционально) |

### 2.2 Имя файла

```
revision-<Склад>-<YYYY-MM-DD>.csv
revision-<Склад>-<YYYY-MM-DD>.xlsx
```

Например: `revision-ЦС-01-2026-04-27.csv`

### 2.3 Пример CSV экспорта

```csv
# Склад: ЦС-01
# Дата ревизии: 2026-04-27
Артикул;Штрихкод;Наименование;ЕдиницаИзмерения;ОстатокПоДанным1С;ФактическоеКоличество;Расхождение;Комментарий
COFFEE-500;8901234567890;Кофе зерновой Premium 500г;шт;150;148;-2;
TEA-100;8901234567891;Чай зелёный органик 100г;шт;200;205;5;
CHOC-100;8901234567892;Шоколад тёмный 100г;шт;300;300;0;
```

### 2.4 Технические параметры экспорта

- **CSV:** UTF-8 с BOM (Excel на Windows открывает кириллицу корректно), разделитель `;`
- **XLSX:** Файл содержит один лист «Ревизия» с метаданными (склад, дата) и таблицей результатов

## 3. Как выгрузить остатки из 1С Розница

### 3.1 Через стандартный отчёт «Остатки на складах»

1. Откройте **1С: Розница** → меню **«Склад»** → **«Остатки на складах»**  
   *(или: Отчёты → Товарные запасы → Остатки на складах)*
2. Выберите **склад** в параметрах отчёта.
3. Нажмите **«Сформировать»**.
4. В меню отчёта нажмите **«Сохранить»** (иконка дискеты) → выберите **«Таблица значений (.xlsx)»** или **«Текстовый документ (.csv)»**.
5. Сохраните файл.

> ⚠️ Убедитесь, что в колонках отчёта присутствуют: **Артикул**, **Наименование**, **Остаток**. При необходимости настройте колонки отчёта через кнопку «Ещё → Изменить вариант».

### 3.2 Через внешнюю обработку (для 1С-программиста)

Можно написать обработку, которая выгружает данные напрямую в нужный формат:

```bsl
// Пример выгрузки остатков в CSV
Процедура ВыгрузитьОстатки(Склад, ИмяФайла)
    Запрос = Новый Запрос;
    Запрос.Текст = 
        "ВЫБРАТЬ
        |    Товары.Номенклатура.Артикул КАК Артикул,
        |    Товары.Номенклатура.НаименованиеПолное КАК Наименование,
        |    Товары.Номенклатура.ЕдиницаХраненияОстатков.Наименование КАК ЕдиницаИзмерения,
        |    СУММА(Товары.КоличествоОстаток) КАК Остаток,
        |    Товары.Номенклатура.ЦенаПродажи КАК Цена
        |ИЗ
        |    РегистрНакопления.ТоварыНаСкладах.Остатки(, Склад = &Склад) КАК Товары
        |СГРУППИРОВАТЬ ПО
        |    Товары.Номенклатура";
    Запрос.УстановитьПараметр("Склад", Склад);
    
    Результат = Запрос.Выполнить().Выгрузить();
    // ... запись в CSV/XLSX файл
КонецПроцедуры
```

## 4. Как загрузить результаты ревизии в 1С

### 4.1 Через документ «Инвентаризация товаров»

1. В **1С: Розница** создайте новый документ **«Инвентаризация товаров»**  
   *(Склад → Инвентаризация товаров → Создать)*
2. Укажите **склад**.
3. На вкладке **«Товары»** нажмите **«Заполнить»** → **«Загрузить из файла»**.
4. Выберите файл результатов ревизии (`revision-*.xlsx` или `revision-*.csv`).
5. Сопоставьте колонки файла с реквизитами документа:
   - `Артикул` → «Артикул» (для поиска номенклатуры)
   - `ФактическоеКоличество` → «Количество факт»
6. Нажмите **«Загрузить»** и **«Провести»** документ.

### 4.2 Через стандартную обработку «Загрузка данных из табличного документа»

Если в конфигурации доступна обработка **«Загрузка данных из табличного документа»**:

1. Откройте обработку.
2. Выберите объект загрузки — **«Документ.ИнвентаризацияТоваров»**.
3. Загрузите файл результатов ревизии.
4. Сопоставьте колонки и нажмите **«Загрузить»**.

## 5. Совместимость

| Система | Версия | Метод выгрузки |
|---------|--------|---------------|
| 1С: Розница | 2.3, 3.0 | Отчёт «Остатки на складах» → Сохранить как |
| 1С: Управление торговлей | 11.x | Отчёт «Ведомость по товарам на складах» |
| 1С: УНФ | 3.x | Отчёт «Остатки и обороты» |
| SAP | любая | Экспорт из транзакции MB52 / MI9 в Excel |
| Excel / Google Sheets | — | Любой файл с нужными колонками |
