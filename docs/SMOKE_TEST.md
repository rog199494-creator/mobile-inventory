# Smoke Test — Мобильная инвентаризация

Ручные проверки перед каждым продакшн-деплоем.

## Окружение

- URL: `https://minitest.bitrixabd.ru/inventory/`
- Telegram Mini App: `@ab_mini_test_bot`

---

## Чек-лист

### 1. Браузер — основной экран
- [ ] Открыть `https://minitest.bitrixabd.ru/inventory/` в **инкогнито**
- [ ] Виден главный экран «Мобильная инвентаризация»
- [ ] В DevTools → Application → Manifest — `<meta name="build-id">` содержит свежую метку времени
- [ ] В консоли **нет** ошибки `Failed to parse KV key response`

### 2. Deep-link по storeId
- [ ] Открыть `https://minitest.bitrixabd.ru/inventory/?storeId=<id>`
- [ ] Приложение сразу открывает карточку нужного объекта (не главный экран)
- [ ] При несуществующем id — показывается toast-ошибка

### 3. Отладочный оверлей safe-area
- [ ] Открыть `https://minitest.bitrixabd.ru/inventory/?debug=safe-area`
- [ ] В левом верхнем углу виден зелёный оверлей с полями:
  - `--safe-area-top`
  - `contentSafeAreaInset.top`
  - `safeAreaInset.top`
  - `platform`
  - `viewport`
  - `inTelegram`

### 4. Заголовок в Telegram
- [ ] Открыть Mini App через `@ab_mini_test_bot` на **iOS или Android**
- [ ] Заголовок «Мобильная инвентаризация» **полностью виден** — не перекрыт часами / Dynamic Island
- [ ] После скролла вниз и обратно — заголовок возвращается на место без перекрытия

### 5. Создание пустой сессии + сканирование
- [ ] Нажать «Новая сессия» → создать без файла
- [ ] Перейти в сессию → нажать кнопку камеры
- [ ] Отсканировать штрихкод — появляется подтверждение
- [ ] Рамка визира **небольшая** (не на весь экран), вписывается в середину камеры
- [ ] Переключить режим Стандарт / Широкий / Точный — рамка меняет размер
- [ ] Завершить сессию → переход на экран анализа

### 6. Импорт из файла (XLSX)
- [ ] Нажать «Импорт из 1С»
- [ ] Загрузить файл `.xlsx` с колонками: Артикул, Наименование, Количество
- [ ] Сессия создаётся с импортированной номенклатурой
- [ ] Показывается количество импортированных позиций

### 7. Персистентность сессий
- [ ] Создать сессию
- [ ] Полностью закрыть Telegram (swipe из списка недавних, не просто свернуть)
- [ ] Открыть снова → Mini App → сессия **на месте** в списке

### 8. Тёмная тема
- [ ] Включить тёмную тему в системных настройках / Telegram
- [ ] Приложение переключается на тёмную тему автоматически

### 9. Оффлайн-режим
- [ ] Отключить интернет
- [ ] Отсканировать штрихкод — появляется предупреждение «Офлайн»
- [ ] Включить интернет — появляется «Связь восстановлена»

### 10. Сборка без ошибок
```bash
cd mobile-inventory
npm install --legacy-peer-deps
npm run build
grep "build-id" dist/index.html   # должен вывести строку с meta
grep "src=" dist/index.html        # должна быть ссылка на assets/index-XXXX.js
```
